OSS · Scene 01

Agent Frameworks & Orchestration

Wire models, tools, state and human approval into a workflow that can run, retry and resume. Decide whether you need a state machine before choosing an abstraction.

See all in this scene → Compare first 3 Home
34selected repos
For people turning multi-step tasks into reliable workflows; single-turn Q&A does not need a framework.Who it is for

How to choose

• Branches, retries and human approval: start with LangGraph.
• First multi-agent setup with quick role division: CrewAI is easier to grasp.
• Type safety and long maintenance: Pydantic AI; minimal code execution: smolagents.
Not for: Do not add multiple agents just for the label. Many tasks need one model and two tools.
