OSS · Scene 06

Evaluation & Observability

Measure quality and trace failures: choose tools that record prompts, retrieval, tool calls, latency and cost.

See all in this scene → Compare first 3 Home
12selected repos
For teams shipping agents or RAG and needing regression tests.Who it is for

How to choose

• Start with a small labelled set and a failure taxonomy.
• Trace every step: Langfuse and similar tools; offline scoring: promptfoo.
• Track cost and latency beside quality; a score alone is not a release gate.
Not for: Do not optimise a dashboard before defining what a failure looks like.
