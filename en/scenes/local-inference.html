Local Inference & Serving

Run models on hardware you control: check quantisation, memory fit, concurrency and serving API before choosing.

See all in this scene → Compare first 3 Home
15selected repos
For privacy-sensitive work, offline use or predictable long-running cost.Who it is for

How to choose

• First local run: Ollama; production serving: vLLM or SGLang.
• Mac or small VRAM: check quantised formats and unified memory.
• Measure tokens/s and time-to-first-token on your own workload.
Not for: Do not assume a 7B model replaces a frontier model on hard reasoning.
