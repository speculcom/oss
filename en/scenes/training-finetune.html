OSS · Scene 07

Training & Fine-tuning

Turn a base model into your own: from single-GPU QLoRA to multi-node RLHF, start with VRAM, parallelism and reproducibility.

See all in this scene → Compare first 3 Home
20selected repos
For people who need to change model behavior, adapt to a domain or run alignment training; inference-only work does not need this scene.Who it is for

How to choose

• 24 GB single GPU, 7B model: start with Unsloth.
• Turn fine-tuning into a reproducible config: Axolotl.
• DPO/PPO/GRPO alignment: start with TRL, scale with verl / OpenRLHF.
• Large-model or multi-node training: DeepSpeed, TorchTitan.
• MoE does not fit locally: KTransformers expert offload.
Not for: Do not choose full-parameter training by default; most domain adaptation is served by LoRA/QLoRA. Estimate data volume and eval gain first.

适合单卡 24GB 就能微调 7B 级模型，适合个人与小团队。把数据、训练与导出收在同一套配置里，第一次微调不用拼多个库。配置驱动，实验可复现，适合把微调流程固化。只训练少量参数，显存与存储成本远低于全参微调。训练、推理、评测与部署在同一套命令里，少写胶水代码。与 transformers 生态无缝，模型、分词器、数据集直接复用。训练循环写得薄，便于读源码和改数据、损失与采样。ZeRO 分片让单机多卡能训更大模型。官方维护，和 PyTorch 新特性同步快。为 Agentic RL 设计，能把工具调用轨迹纳入训练。把推理、奖励、训练分成可扩展的 Ray actor。MoE 模型不必全部塞进显存，适合本地大模型。想理解千卡级训练怎么切模型和激活，Megatron 是事实标准，很多大模型训练栈基于它改。GUI 把复杂训练参数摊开，适合个人与小队做角色/风格 LoRA。把训练脚本拆成可读配方，适合学习与中小规模微调。单卡训练脚本加一行 launch 就能跑多卡。一行读取 Hub 数据集，版本与 schema 有记录。同一套 API 从笔记本扩到集群，不用先上 K8s。把模型预标注、人工复核和数据集版本放在一条流里。一个界面覆盖多数模态，省去多套标注工具。
不适合要做大规模预训练或多机多卡，仍应看 DeepSpeed / TorchTitan。要做超大规模预训练或多机极限吞吐，应看 Megatron 系与 TorchTitan。不想读 YAML、只想点按钮的人，应先看托管平台。需要改变模型知识边界或做大规模继续预训练，单靠适配器不够。只在 Hugging Face 生态内工作、且不需要 ModelScope 模型时，依赖会更重。只做推理或简单微调，直接用 transformers Trainer 更轻。想要开箱 WebUI 与大量现成模型模板，LLaMA-Factory 更省事。小模型单卡微调，用不到这么重的分布式栈。只想微调一个小模型，直接用 Hugging Face Trainer。只做 SFT，不需要这么重的 RL 栈。单卡小实验，直接用 TRL 更简单。追求通用、稳定的生产推理，优先 vLLM/SGLang。单卡或小集群微调；配置和并行调优门槛高，小团队用 torchtune/DeepSpeed 更轻。不是一键出图产品；数据清洗、打标与参数调试决定结果。不是大规模分布式训练平台；千卡级训练仍用 Megatron/DeepSpeed。不是完整训练框架；数据加载、实验管理和评测仍要自己搭。不是数据治理平台；许可、PII 与去重仍要自己审。不是 Kubernetes 替代；集群运维、网络与存储仍要自己做。不是标注外包服务；标注指南与质控仍要自己定。开源版与企业版功能不同，商用前读条款。
