Accelerate

huggingface / accelerate

Pulls PyTorch’s multi-GPU, TPU, mixed-precision, gradient-accumulation, FSDP and DeepSpeed boilerplate into one API: device placement, distributed launch and AMP without hand-written scaffolding.

9.9k stars 1611 forks Python Language Apache-2.0 License Last push 2026-11-18

Why choose it

  • A single-GPU script can launch multi-GPU with one command.
  • Works with custom training loops, not only the Transformers Trainer.
  • Centralizes FSDP / DeepSpeed configuration and removes distributed boilerplate.

Not for

Not a complete training framework; data loading, experiment tracking and evaluation are still yours.
Multi-node communication depends on NCCL and networking; misconfiguration is expensive to debug.
Extreme scale still needs dedicated sharding and fault tolerance.

Minimum setup

  1. pip install accelerate, then run accelerate config to generate a default setup.
  2. Launch a single-GPU script with accelerate launch to verify device and AMP.
  3. Then enable multi-GPU/FSDP and record throughput and VRAM against the single-GPU baseline.

Dependencies and cost

Python + PyTorch; multi-GPU needs NCCL and intra-/inter-node networking; DeepSpeed/FSDP add dependencies and VRAM budget.

License and usage boundaries

Apache-2.0; bundled or optional DeepSpeed, Transformer Engine and other components carry their own licences.

Open source is not automatically commercial-use friendly: GPL / AGPL are copyleft; code, model and output licenses are separate. Read the LICENSE and model card before launch, and involve legal when needed.

Alternatives and neighbors

  • DeepSpeed — Scale / performance，Microsoft's large-model training library: ZeRO, offload, mixed precision and MoE training to make VRAM and throughput usable.
  • LitGPT — Production，Lightning AI’s lightweight recipes for LLM training, fine-tuning and deployment: 20+ models, pretraining, SFT, LoRA, quantisation and inference, with an emphasis on single-GPU runs and readable code.
  • Axolotl — Production，One YAML config for fine-tuning: LoRA, QLoRA, full-parameter, DPO, GRPO and multi-node training.

Next steps

  • Open GitHub and read the README, LICENSE, latest release and issues first.
  • Make an onboarding checklist for deployment dependencies, VRAM, data, network and permissions.
  • Run a small sample first, then decide on production; never start with production data.
